Research

Centromeres are the part of the chromosome that gets pulled on when a cell divides. If that goes wrong, cells end up with the wrong number of chromosomes, which is linked to cancer and infertility. You'd expect a region that important to be conserved. It isn't: centromeric DNA is mostly repeats, and it gets rewritten quickly between species. This is known as the centromere paradox, and it's what my PhD is about.

On the computational side I use long-read genomes, phylogenomics, comparative and 3C genomics, and protein language models. A lot of the work ends up being writing tools to measure things that couldn't easily be measured before.

Projects

  • Cyclical evolution of centromeres · in review, 2025

    Comparing centromeres across 193 eukaryotes, we see a repeating pattern rather than random drift: satellite arrays expand, homogenise, get invaded by transposons, collapse, and start again.

  • DToL Centromere Atlas · web tool

    An interactive tree of 325 Darwin Tree of Life species showing centromere type, satellite repeats and transposon content for each.

  • CHARLA · Nextflow pipeline

    Finds crossover breakpoints in single long reads from hybrid Arabidopsis pollen using k-mers, including inside the centromere.

  • Pore-C pipeline · wet lab + analysis

    Long-read chromosome conformation capture, used to look at how centromeric DNA folds in the nucleus.

  • Enzyme mining from metagenomes · MSc thesis, 2024

    Phylogenomic search for functional enzyme variants in metagenomic data. Won first place at the EELISA student competition in Budapest.

  • HiFi assembly tutorial · teaching

    A step-by-step walkthrough of assembling a genome from PacBio HiFi reads.
